## How to use
- Create an venv and install the dependent libraries. See section 'Requirements' in this readme.
- Make sure initial folder structure is present. See section 'Folder structure' in this readme.
- Change the file name of `config_template.yaml` to `config.yaml`, and change the variables accordingly.
- Change settings in `main.sh` and check if pipes of interest are active.
- If pipe pdf2xml is active in `main.sh`; make sure to run `bash start_grobid_a19.sh` first, before running `main.sh`. (Check with `curl <servername>:<portname>` if GROBID is alive.)
- Run the application by entering `bash main.sh` in the terminal.
#### WARNING: Path to where data will be written (`data/`) is currently hard-coded. Make sure that there is enough disk space to avoid disappointments. See section 'Possible data output' in this readme for more information.
