## How to use
- Create an venv and install the dependent libraries (see 'Requirements' on this page).
- TODO:Make sure the following folder structure is present. 
- Change the file name of `config_template.yaml` to `config.yaml`, and change the variables accordingly.
- TODO: Make sure that `config.yaml` is in the same location as `main`.
- Change settings in `main.sh` and check if pipes of interest are active.
- If pipe pdf2xml is active; make sure to run `bash start_grobid_a19.sh`. (Check its settings before running it and check with `curl <servername>:<portname>` if it is alive.)
- TODO: Run the application by entering `bash main.sh` in the terminal.

- `corpus2vector.py` runs on a gpu server. A separate .sh file is made. To run it enter `sbatch corpus2vector.sh`

- Use the jupyter notebooks in folder `explorations` to analyse created sentence embedding and similarity scores.

Copilot (version 1.7.4421) was used for this project. It helped with writing docstrings and generating regex expressions for sentence extraction. Note that it is disclosed in the comments if the code was generated by Copilot.
