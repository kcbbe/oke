meta2xml

Download full scientific XMLs by using column work_id from the metadata CSV file.

This module downloads full scientific papers as XML by using the OpenAlex API by providing it with work_id that is found in the metadata CSV file for PMIDs. After downloading, it reports which errors it encountered when failing to retrieve a XML.

Usage:

python meta2xml.py -i pmids_in.csv -m efficient

param -c:

Path to the configuration file (default: ‘config.yaml’)

param –config_file:

Path to the configuration file (default: ‘config.yaml’)

param -i:

Name of the input file, incl. its suffix.

param –input_file:

Name of the input file, incl. its suffix.

param -m –query_mode:

Query mode to use on OpenAlex. (default: ‘efficient’) Choose between ‘efficient’ or ‘full’ search. ‘efficient’ will only query PMIDs that are not present in destination folder, ‘full’ search will query all PMIDs provided in input file.

Input:

A CSV file with one column header named ‘pmid’, were the values corresponds to its PubMed Identifier. And one column header named work_id with work ids from OpenAlex. A configuration file (config.yaml) is required. Please make sure the correct email address is in the configuration file (config.yaml).

Output:

XMLs are downloaded to ‘./data/xml_papers/’. It reports which errors it encountered when failing to retrieve a XML.

meta2xml.get_xml_papers_from_url(work_ids: dict, YOUR_KEY: str, mode: str) → list

Download xml papers from (OpenAlex) work_ids.

Take a dictionary of PMIDs and their corresponding work_ids as input, attempt to download the xmls (if it does not already exists), and save them to ‘./data/xml_papers’. Collect error information of failed downloads.

Parameters:

work_ids (dict) – PMID is key and work_id is value. For example: {‘27634977’: ‘W2519408637’ , … }

Returns:

For example: [[‘pmid’, ‘error_code’, ‘error_message’], [‘22420260’, 403, ‘Forbidden’], …]

Return type:

collect_errors (list)

meta2xml.main()

Download full scientific papers in xml.

This function is the main entry point of the meta2xml.py script. Collect arguments, retrieve PMIDs from the input file, exclude already downloaded PMIDs, retrieve xml URLs from the meta data file, and download the xmls. It also reports metrics and errors to log files.
